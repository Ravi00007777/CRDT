Three classic options. Locking is simple but defeats the purpose. Operational Transform is what Google Docs uses: a central server rewrites every operation against the ones that happened concurrently. It works, but writing correct transform functions is famously error-prone. CRDTs — conflict-free replicated data types — push the merge logic into the data structure itself, so replicas converge no matter what order updates arrive in. That also makes offline editing and reconnection natural. I chose a CRDT, specifically Yjs, a mature open-source implementation, rather than writing my own: the project’s contribution is building a correct, secure, durable system around it.
