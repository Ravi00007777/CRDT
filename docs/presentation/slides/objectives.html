SyncSpace · B.Tech Project

3

Four guarantees drove every design decision. Real-time: edits show up for others without refreshing. Conflict-free: concurrent edits converge to the same document and nothing valid is dropped. Durable: a refresh or a server restart never loses saved content. Secure: knowing or guessing a document’s ID is not enough to read or join it. Each of these is backed by an automated test, which I’ll show later.
