The system has three parts. The browser runs a React app with the Tiptap rich-text editor bound to a Yjs document — each browser holds a full local replica. It talks to one Node process over two channels: plain REST for login, the dashboard and sharing, and a WebSocket for live collaboration through Hocuspocus, an open-source Yjs server. REST and WebSocket share a single authorization function, so the rules can’t drift apart. PostgreSQL, through Prisma, stores users with bcrypt-hashed passwords, documents with their binary Yjs state, and access grants. Important: the binary Yjs state is the canonical document; we never save HTML as a substitute. Keeping REST and WebSocket in one process was a deliberate choice: revoking access needs to reach live connections, which I’ll come back to.
