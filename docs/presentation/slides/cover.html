Good morning. My project is SyncSpace, a Google Docs–style editor where several people can type into the same document at the same time. The interesting part is not the editor UI but the distributed-systems problem underneath: keeping every copy of the document identical when edits happen concurrently, without losing anyone’s work, and keeping it durable and secure.
