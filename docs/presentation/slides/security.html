Security was designed threat by threat. The most important one for a collaborative editor: a user must not get into a document by guessing or changing the room ID in the URL. Every WebSocket join runs the same access check as the REST API, and the API returns 404 for documents you can’t see, so it doesn’t even reveal which IDs exist. The session lives in an httpOnly cookie, so JavaScript — including any injected script — can’t read it, and no long-lived token ever appears in a WebSocket URL. Browsers send cookies on cross-site WebSocket connections, so the server checks the Origin header on every upgrade. Inputs are validated with Zod with size limits, and passwords are bcrypt-hashed. All the secrets come from environment variables, never from the repository.
