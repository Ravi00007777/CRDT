Being upfront about the limits. All collaborators are editors — roles would be a small schema change plus marking connections read-only. Persistence is debounced: a normal shutdown flushes everything, but a hard crash or power loss can lose up to about five seconds of edits; the fix is an append-only update log. It runs as one server process; scaling out would use the Redis extension so instances share updates. Document titles go through the REST API, so collaborators see a rename on their next load. And there’s no version history yet, which Yjs snapshots would enable. None of these change the core design.
