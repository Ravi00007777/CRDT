Testing was treated as evidence, not decoration. The server integration suite starts the real server against a real Postgres test database and drives it with headless Yjs clients: it checks input validation, that other users can’t see private documents, two-client sync and convergence, room isolation, that unauthenticated or unauthorised WebSocket joins are refused, the share-then-revoke flow, and recovery after actually stopping and restarting the server. All seven pass. The Playwright suite opens two separate browser contexts — two different users — and checks live typing, headings syncing as structure, concurrent typing ending in identical document HTML, remote cursor labels, presence going from two to one on disconnect, reload, privacy and deletion. All three pass, and they passed again on a repeat run. The load test is on the next slide.
