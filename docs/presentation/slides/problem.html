Safe, but only one writer at a time. Nobody collaborates.

What we want

Everyone types at once. Every edit survives. Every copy ends up identical.

Concurrent editing is a classic distributed-systems problem. If two people edit the same document and we just save whatever arrived last, one person’s change is silently lost. Locking avoids that but kills collaboration. Small example at the bottom: the document says “cat”. Alice appends an s, Bob prepends “a ”. Last-write-wins gives either “cats” or “a cat”; the correct merge keeps both intents: “a cats”. The goal is to get that result automatically, for every client, every time.
