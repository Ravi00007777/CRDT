The load test connects many headless clients to one document; each client concurrently makes random inserts and deletes in a shared text. At the end, I check that every client’s state vector — Yjs’s summary of which updates it has — is identical, and that the text is identical. With 10 clients and 100 operations each, all replicas ended identical in all three runs, and convergence took 21 to 22 milliseconds after the last edit. Scaling to 50 clients and 200 operations each, ten thousand operations, the result was still identical and converged in 46 milliseconds. Caveat: this is one machine on localhost, so it measures the sync logic and server, not real network latency. The final length being slightly above inserts minus deletes is expected: when two clients delete the same character at the same time, it is only deleted once.
